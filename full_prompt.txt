# MASTER DEVELOPMENT PROMPT — EDU EVAL AI

## PROJECT TITLE

EduEval AI — AI-Powered Academic Evaluation and Student Feedback System.

## 1. PROJECT OBJECTIVE

Develop a complete, functional, secure, and responsive academic evaluation platform for educational institutions.

The application must have three separate login portals:

1. Admin.
2. Faculty.
3. Student.

Students upload their academic assignments, journals, presentations, and assessment reports.

Faculty members upload the complete course profile, syllabus, reference materials, learning objectives, and marking rubrics.

When faculty members select a student submission and trigger AI evaluation, the system must retrieve relevant course information using a local RAG pipeline and send the necessary academic content to the OpenAI API for analysis and feedback generation.

The system must generate:
- Estimated marks.
- Criterion-wise scores.
- Conceptual understanding analysis.
- Strengths and weaknesses.
- Missing concepts.
- Supporting evidence.
- Personalized improvement suggestions.
- Overall academic feedback.

All AI-generated scores must remain provisional until faculty approval.

IMPORTANT:
Do not train a large AI model for this prototype. Use the Hybrid architecture consisting of local RAG, OpenAI API, and our own Python rubric-scoring engine.

## 9. LOCAL RAG PIPELINE

Implement a complete Retrieval-Augmented Generation pipeline.

Use:

- Sentence Transformers for local embeddings.
- FAISS for local vector search.
- Python for retrieval orchestration.

Workflow:

1. Extract text from faculty course profile documents.
2. Split text into appropriate chunks.
3. Generate embeddings locally.
4. Store embeddings in FAISS.
5. Associate each chunk with its subject, source document, and page number.
6. Receive a faculty evaluation request.
7. Retrieve the appropriate course profile.
8. Identify relevant content from the student's submission topic.
9. Retrieve the most relevant reference passages.
10. Pass the relevant academic context to OpenAI.

Do not send the entire institution database to OpenAI.

Keep retrieval subject-specific and assessment-specific.

If no relevant course content is found, warn the faculty member and avoid pretending that a proper course-based evaluation has occurred.
